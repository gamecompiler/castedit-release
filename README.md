# CastEdit

**방송 녹화를 받아서 유튜브에 올리기까지, 한 앱에서.**

CastEdit는 인터넷 방송인을 위한 윈도우용 편집 앱입니다. 몇 시간짜리 방송 녹화본을 그대로 열어 필요한 구간을 고르고, 받아쓰기로 자막을 만들고, 자막을 보면서 말 단위로 다듬고, 효과를 얹고, 롱폼과 숏폼으로 나눠 내보내고, 유튜브에 올리는 데까지 앱 하나로 합니다.

> 이 페이지는 사용 설명서입니다. 설치 파일은 오른쪽(휴대폰이면 아래)의 **Releases**에 있습니다.

---

## 왜 만들었나

방송 하나를 편집본으로 만드는 데 프로그램을 여럿 거쳐야 했습니다. 큰 구간은 LosslessCut으로 자르고, 그 파일을 다시 잘라 합치고, 프리미어로 컷 편집을 하고, 소리를 따로 뽑아 Subtitle Edit에서 받아쓰기와 교정을 하고, 자막 파일을 다시 프리미어에 얹고, 마스터링을 하고, 내보내고, 유튜브에 올렸습니다. 프로그램을 옮길 때마다 파일이 하나씩 생기고, 앞 단계를 고치면 뒤 단계를 다시 해야 했습니다.

CastEdit는 이 흐름을 하나로 합치려고 만들었습니다. 지키는 원칙은 다음과 같습니다.

- **원래 쓰던 프로그램보다 못하면 안 된다.** 기능을 모으면서 빠지는 핵심 기능이 있거나 원래 프로그램보다 느려지면 합친 의미가 없습니다. 단축키도 손에 익은 배치를 따릅니다. 편집은 프리미어, 자막은 Subtitle Edit, 큰 구간은 LosslessCut 배치입니다.
- **재생하면서 결과를 본다.** 효과·자막·효과음·배경음악이 평소 재생 화면에서 그대로 보이고 들립니다. 재생 화면에 보이는 것과 내보낸 결과가 같습니다.
- **원본은 건드리지 않는다.** 녹화 파일은 그대로 두고 편집 내용만 저장합니다. 중간 병합 파일도 만들지 않습니다. 큰 구간을 나중에 고쳐도 그 안의 컷·자막·효과가 그대로 따라옵니다.
- **방송인의 녹화에 맞춘다.** 마이크·게임·손님(디스코드)·알림을 트랙별로 따로 녹화한 파일을 그대로 열고, 트랙마다 역할을 정해 둡니다. 컷은 마이크 기준으로 하되 게임 소리는 배경처럼 끊기지 않게 이어 붙이는 식으로, 방송 편집에서 자주 하는 처리를 기본으로 합니다.
- **사람이 손으로 하던 판단을 앱이 먼저 제안한다.** 받아쓰기, 헛말·침묵 찾기, 하이라이트 탐지, 자동 편집안까지 앱이 먼저 만들고, 사람은 검수하며 고칩니다. 하이라이트 탐지 같은 분석은 AI 없이 앱 안에서 돌아가므로 토큰을 쓰지 않습니다. AI는 맥락을 읽어야 하는 일에만 쓰고, 그 경우에는 따로 표시합니다.
- **만든 파일은 한곳에.** 캐시·썸네일·임시 파일 같은 부산물이 녹화 폴더에 흩어지지 않게, 앱이 관리하는 작업 폴더 한 곳에 모으고 다 쓰면 정리합니다.
- **비밀 값은 파일에 두지 않는다.** 유튜브·치지직 연결, 웹후크 같은 비밀 값은 윈도우 자격 증명에만 저장합니다.

## 설치

1. [Releases](../../releases/latest)에서 **`CastEdit-Setup-버전.exe`**를 받아 실행합니다.
   - 관리자 권한 없이 설치되고, 시작 메뉴와 바탕화면에 아이콘이 생깁니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명하지 않은 개인 제작 프로그램이라 뜨는 창입니다.
   - 설치하지 않고 쓰고 싶으면 `CastEdit-버전-windows.zip`을 받아 **압축을 모두 푼 다음** `CastEdit.exe`를 실행하세요. `CastEdit.exe`만 따로 꺼내면 실행되지 않습니다(옆의 `_internal` 폴더가 함께 있어야 합니다).
2. 처음 켜면 **언어**(한국어 / English)와 **설정 프리셋**을 고릅니다. 잘 모르겠으면 기본값으로 시작하세요.
3. 영상을 다루는 데 필요한 **ffmpeg**가 PC에 없으면 앱이 알아서 받습니다(처음 한 번, 100MB 안팎). 화면 위쪽 띠에 진행 상황이 보입니다.
4. 재생 중에 효과·자막을 그리는 재생 엔진(libmpv)도 처음 한 번 저절로 받습니다. 받아쓰기 엔진(Whisper)은 **파일 → 설정 → 엔진 관리**에서 버튼 하나로 받습니다. Subtitle Edit를 이미 쓰고 있다면 거기 받아 둔 Whisper를 찾아 그대로 씁니다.

**업데이트**: 앱을 켤 때 새 버전이 있는지 확인하고 물어봅니다. 받으면 앱이 잠깐 닫혔다가 새 버전으로 다시 켜집니다. **파일 → 업데이트 확인…**으로 직접 확인할 수도 있습니다.

**권장 환경**: Windows 10/11 64비트. NVIDIA 그래픽카드가 있으면 받아쓰기와 내보내기가 훨씬 빠릅니다. 없어도 CPU로 동작합니다(설정 → 음성 인식 장치를 cpu로, 내보내기 코덱을 libx264로).

## 화면 둘러보기

화면 맨 위에 **작업 공간** 네 개가 있습니다. 같은 프로젝트를 편집하면서 화면 배치와 무엇을 고르는지만 바뀝니다.

| 키 | 작업 공간 | 하는 일 |
|---|---|---|
| `F1` | 구간 | 녹화 원본에서 쓸 큰 구간을 고릅니다 (LosslessCut처럼) |
| `F2` | 편집 | 편집본을 보며 컷을 다듬고, 자막을 고치고, 효과를 넣습니다 |
| `F3` | 효과 | 효과 설정과 효과 목록을 크게 펼쳐 세부 값을 조정합니다 |
| `F4` | 내보내기 | 롱폼·숏폼을 나누고 결과를 확인한 뒤 내보내고 올립니다 |

- 가운데는 **재생 화면**, 아래는 **타임라인**(트랙별 파형과 편집점), 옆은 **자막 목록**과 **효과 설정**입니다.
- 재생 화면을 뺀 창은 끌어서 옮기고, 떼어 내고, 크기를 바꿀 수 있습니다. 배치는 작업 공간마다 따로 기억합니다. **창** 메뉴에서 창을 켜고 끄거나 처음 배치로 되돌립니다.
- 단축키로만 하던 기능도 버튼이 있고, 버튼에 마우스를 올리면 설명과 단축키가 나옵니다.
- 메뉴는 갈래로 나뉩니다: **파일**(열기·저장·내보내기) · **편집** · **자막** · **보기** · **창** · **효과** · **합방** · **탐지** · **AI** · **컨텐츠** · **도구**(방송·자료·만들기) · **설정**(설정·연동·컨텐츠 연결·재생 엔진·에셋 폴더) · **도움말**. 기능 이름을 모르면 `Ctrl+Shift+P`로 찾습니다. 키로 연 창은 같은 키를 다시 누르면 닫힙니다.
- 글꼴 칸은 누르면 목록이 펼쳐집니다. 맨 위는 즐겨찾기(☆를 누르면 ★)이고, 칸 오른쪽에는 최근에 고른 글꼴이 있어 바로 고를 수 있습니다. 색 칸은 팔레트와 스포이드(**화면 색 고르기**)로 고릅니다. 암호 칸은 오른쪽 끝의 눈을 누르면 글자가 보입니다.

## 기본 편집 흐름

### 1. 열기
`Ctrl+O`로 녹화 파일을 고르거나, 창에 끌어다 놓습니다. **녹화 하나가 프로젝트 하나**이고, 모든 변경은 2초 뒤 자동 저장됩니다. 같은 녹화를 다시 열면 이어서 편집합니다. 닫을 때는 `Ctrl+W`(저장하고 빈 화면으로)입니다.

처음 열면 **트랙 배치**(프로젝트 → 트랙 배치)를 확인하세요. 녹화 파일의 오디오 트랙 T1, T2 …마다 이름과 역할(내 목소리·게임·손님·알림 등)을 정합니다. 녹화 프로그램에서 붙인 트랙 이름으로 앱이 먼저 짐작합니다.

### 2. 큰 구간 고르기 (`F1`)
방송에서 쓸 부분만 고릅니다. 원본 보기에서 `I`(시작)와 `O`(끝)를 누르면 바로 구간이 생깁니다.
- 구간 오른쪽에서 `O`를 누르면 그 구간이 여기까지 늘어나고, 구간 안에서 누르면 그 구간의 시작·끝이 옮겨집니다.
- `B`를 누르면 재생 위치에서 구간이 둘로 나뉩니다. 구간을 고르고 `Del`을 누르면 빠집니다.
- 숫자 `1` `2` `3`은 구간마다 게임 소리를 다루는 방식입니다. `1` 솔로 플레이(게임 소리도 같이 컷), `2` 솔로 내레이션(게임 소리는 끊기지 않게), `3` 합방(게임 소리 없음).

### 3. 받아쓰기 (`Ctrl+T`)
고른 구간만 받아써서 자막을 만듭니다. 마이크 트랙이 기본이고, 합방이면 손님 트랙도 함께 받아씁니다. 받아쓰는 동안에도 편집을 계속할 수 있고, 나중에 구간을 추가하면 새 부분만 받아씁니다.

받아쓰기는 숨 쉬는 곳에서 줄을 끊어서, 한 문장이 두 줄로 나뉘거나 두 문장이 한 줄에 붙기도 합니다. **자막 → 문장 단위로 다듬기**를 쓰면 이을 곳과 나눌 곳을 제안하고, 고른 것만 바꿉니다.

### 4. 정밀 컷 (`F2`)
자막을 보면서 말 단위로 자릅니다.
- 자막 줄을 고르고 `Del`을 누르면 그 말이 잘립니다. 다시 누르면 되살아납니다.
- **자막 → 정밀 컷 후보 찾기**는 "어", "음" 같은 헛말, 같은 말 반복, 다시 시작한 문장, 긴 침묵을 찾아 표시합니다. 종류별로 한꺼번에 적용하거나 하나씩 들어 보고 고릅니다.
- **무음 자르기**(타임라인 오른쪽 클릭)는 파형을 함께 보여 줘서 말끝이 잘리지 않게 여유를 정할 수 있습니다. 자막이 없는 구간에도 쓸 수 있습니다.
- 자막 다듬기는 Subtitle Edit 키를 따릅니다(합치기 `Z`, 나누기 `S`, 경계 `E` `R`, 글 고치기 `Enter`).
- `Shift+4`는 편집본 보기(잘린 곳을 건너뛰고 재생), `Shift+2`는 원본 보기입니다.

### 5. 효과 (`F2`·`F3`)
재생 위치에 효과를 넣고, `F3`에서 값을 조정합니다. 효과는 재생하는 동안 그대로 보입니다. `Shift+F`를 누르면 멈춘 화면에서도 효과를 끄고 켜며 비교할 수 있습니다.

### 6. 내보내기 (`F4`)
타임라인이 편집본 전체를 한 줄로 보여 줍니다.

| 키 | 하는 일 |
|---|---|
| `B` | 여기서 롱폼을 나눕니다 (한 방송을 여러 편으로) |
| `I` · `O` | 숏폼으로 쓸 장면(숏폼 대상)의 시작과 끝을 정합니다. I를 누르면 대상 한도(기본 5분)까지 점선으로 보여 줍니다 |
| `E` | 아이캐치를 넣습니다 |

- 롱폼에서 뺄 부분은 F2에서 컷 편집으로 자릅니다.
- **숏폼 컷 편집**: 숏폼은 롱폼 컷에서 시작해서 그 숏폼만 더 자를 수 있습니다. 5분짜리 장면을 롱폼에는 다 보여 주고, 숏폼에서는 2분대로 줄이는 식입니다.
  - 목록에서 숏폼을 고르고 **[숏폼 컷 편집]**을 누르면 타임라인이 그 숏폼만 보여 주고, 위에 `남은 길이 / 2:59`가 크게 보입니다.
  - `I`로 뺄 곳 시작을 잡고 `O`(또는 `Del`)로 거기까지 뺍니다. 뺀 곳 위에서 `Del`을 누르면 되살아납니다. 자막 목록에서 줄을 고르고 `Del`을 누르면 그 말만큼 빠집니다. `Esc`로 끝냅니다.
  - 여기서 자른 것은 그 숏폼에만 적용되고 롱폼은 그대로입니다.
- 숏폼은 빨간 띠로 보입니다. 유튜브 쇼츠 기준(3분 이하)에 여유를 둬서 **2분 59초**를 넘으면 경고가 뜨고, 그 숏폼은 내보내지 않습니다. 대상을 2분 59초보다 길게 잡으면 바로 숏폼 컷 편집으로 들어갑니다.
- 오른쪽 목록에서 영상을 고르면 제목, 인트로·아웃트로 여부, **소리 줄 빼기**(내 목소리·손님·게임·알림·배경음악·효과음·넣은 영상 소리)를 영상마다 정할 수 있습니다. 두 번 누르면 그 영상이 재생됩니다.
- **숏폼 화면 구성**에서는 왼쪽 원본에서 캠·게임·채팅 영역을 잡아 오른쪽 세로 화면에 끌어다 놓고 크기를 바꿉니다. 제목 같은 글자 칸도 넣을 수 있고, 마음에 드는 배치는 기본으로 저장해 다음 숏폼부터 그대로 씁니다.
- 영상 전체가 2분 59초보다 짧으면 롱폼 없이 숏폼으로만 만듭니다.
- **내보내기 · 유튜브 설정…**에서 화질·프레임(원본/30/23.976)·코덱을 고르고, 유튜브 채널·재생목록·예약 공개를 정해 바로 올립니다.

모든 편집은 `Ctrl+Z` / `Ctrl+Shift+Z`로 되돌리고 다시 할 수 있습니다.

## 주요 기능

### 편집
- 프리미어식 편집: 자르기, 잔물결 삭제, 롤링·잔물결·밀어넣기 다듬기, J컷·L컷, 트랙 잠금, 위 트랙(V2 이상) 겹치기
- 구간 속도, 역재생, 흔들림 보정, 색 보정·LUT, 크롭, 크로마키
- 프록시: 긴 녹화도 가볍게 재생하고, 내보낼 때는 원본을 씁니다
- 같은 녹화로 여러 편집본(하이라이트 모음 등)을 따로 만들 수 있습니다

### 자막
- 받아쓰기(Whisper), 고유명사 교정 목록(한 번 고치면 다음 받아쓰기부터 자동으로 고침), 맞춤법 검사
- 자막 싱크를 파형에 맞추기, 문장 단위 정리, 틈 없이 이어지는 자막
- 자막 모양: 글꼴·색·테두리·자리, 내 자막과 손님 자막 따로, 자막 바, 단어 강조
- 다른 영상(PV 등)의 자막 가져오기

### 효과
- 펀치 줌, 서서히 확대, 지정 줌, 카메라 이동, 흔들림, 화이트 플래시, 흑백·회상

- 효과 묶음: 자주 쓰는 효과 조합을 저장해 한 번에 넣습니다

### 방송 도구 (`Ctrl+Shift+B`)
- 송출 PC와 게임 PC 연결, 방송 설정(치지직 카테고리·제목·태그, 장면에 따라 카테고리 바꾸기)
- 화면 보내기, 디스코드 말하는 사람 표시, 주간 일정표 만들기와 올리기, 휴방 공지
- **스트림덱 허브**: 스트림덱 버튼은 CastEdit 기능 이름만 부릅니다(플러그인 없이 기본 'System → Open'). 게임 PC 일(매크로·스크린샷)은 그 자리에서, 송출 PC 일(OBS 장면·소스·음소거·마커, 보이스미터 켜고 끄기, 유튜브 뮤직)은 송출 PC 도우미가 합니다. **도구 → 스트림덱 버튼 만들기**에서 붙여 넣을 줄을 만듭니다
- **프로그램별 매크로·스크린샷** (도구 → 프로그램별 매크로): 키 하나로 앞에 떠 있는 게임을 알아보고 그 게임의 동작(UI 숨기기 → 찍기 → 되돌리기 같은 것)을 합니다. 스크린샷은 게임마다 폴더에 모입니다. 다른 프로그램이 찍은 그림도 게임 폴더로 옮겨 올 수 있습니다

**스크린샷 · 매크로**(도구): 스크린샷은 단축키 하나로 앞에 떠 있는 프로그램을 찍어 그 프로그램 폴더에 넣습니다(프로그램별 폴더는 스크린샷 창에서). 매크로는 프로그램마다 키·클릭·끌기·휠·글자 입력·기다리기를 넣거나 [⏺ 녹화]로 하던 대로 기록합니다(F10 = 멈춤, '간격도 기록' 선택).

**보이스미터 없이 디코 마이크**(송출컴 도우미 → 디코 마이크 섞기): VB-CABLE을 한 번 설치하면 마이크와 게임컴 반주를 앱이 섞어 디스코드로 보냅니다. 디스코드 마이크만 'CABLE Output'으로 한 번 바꾸면 되고, 켜고 끄기는 버튼·스트림덱으로 합니다.

### 컨텐츠
- **웹 슬라이드**: 설명회·토론회용 슬라이드를 만들고, 진행자가 넘기면 보는 사람 화면도 따라갑니다
  - **주제어 만드는 규칙**은 앱에 들어 있습니다: 한 장에 한 축(질문이 둘이면 나누고 같은 이야기는 합침) · 짧게(가설·근거는 대본으로) · 후보 이름을 박지 않고 열린 물음으로 · 방송 채팅 말투(약칭·밈) · 순서는 소감 → 인물 → 사건 → 떡밥 → 세계관 → 다음 예측
  - **[틀·디자인] → 주제어 말투**: 우리 방송의 밈·약칭과 예전에 실제로 바꾼 예를 적어 두면(예: `ㄱㄴ? = '갔나?' — 또 죽었나 싶은 인물의 퇴장`) 주제어를 모으거나 다듬을 때마다 Claude가 읽습니다. 틀로 저장하면 다음 회차에도 그대로 쓰여 매번 설명할 필요가 없습니다
- **낭독**: 글을 비주얼 노벨 화면으로 바꿔 함께 읽는 방송을 합니다. 연재 주소나 직접 넣은 글(괴담 등)을 분석해 화자·장면·배역·그림을 정하고, 문단마다 효과음이나 흔들기 같은 연출을 꽂을 수 있습니다
- **지문 읽는 사람**: 한 사람 · 화마다 한 사람(돌아가며) · 나눠 읽기 중에서 고르고, 특정 화만 손으로 고정할 수도 있습니다(비주얼 노벨 메뉴, 대본 창 회차 목록 오른쪽 클릭)
- **배역 나누기**: 성별·분량을 맞추고, 서로 대화하는 인물은 되도록 다른 사람에게 줍니다. 성별이 다른 사람에게 줄 수밖에 없을 때는 ⚠가 붙고, 누르면 까닭이 나옵니다. 설정 창 참여자 아래에 각자 맡은 배역과 대사 수가, 에피소드 목록에는 화마다 누가 얼마나 읽는지 색 막대가 보입니다
- **낭독회 웹**: 작품(대본 + 비주얼 노벨)을 자기 사이트에 올려, 함께 읽는 사람들이 브라우저로 같은 장면과 전체 대본을 보게 합니다. 진행자가 넘기면 따라오고, 참여 암호·진행 암호를 걸 수 있습니다 (올릴 서버는 직접 정합니다)
- 컨텐츠 연동: 게임·애니메이션마다 일정·그림 폴더·녹화 폴더·참고 영상을 묶어 두고 기능마다 불러 씁니다

### 방송 정리
방송이 끝나면 녹화 파일을 옮기고, 이름을 규칙대로 바꾸고, 다시보기 채널에 올리는 일을 자동으로 합니다(시작 메뉴의 **CastEdit 방송 정리**).

**🖼 썸네일**(도구 → 디자인 → 썸네일, 방송 정리의 🖼): 위에 템플릿(틀)을 그림으로 늘어놓고, 왼쪽에서 작업할 영상을 고르면 노션 부제와 그날 찍은 스크린샷이 미리 깔립니다. 배경은 끌기·휠·Ctrl+휠로 옮기고 키우고 돌립니다. 게임 그림 폴더의 최근 스크린샷에 게임 틀을 씌워 고릅니다. 윗줄은 부제의 버전·회차(예: `3.8 上`), 제목은 꺾쇠를 뗀 부제입니다. 틀 그림·로고·도장은 창의 목록에서 고르고(틀·로고 폴더의 그 게임 이름 폴더에 투명 PNG를 넣고 [다시 읽기]), 익스프레스에서 화면 크기 그대로 받은 그림은 그린 자리 그대로 얹습니다. 지난 방송은 트레이 아이콘 오른쪽 클릭 → **지난 방송 정리 다시 열기**에서 골라 다시 만들 수 있습니다.

### 미디어 받기 (`Ctrl+Alt+D`)
참고 영상·소리·자막을 받아 레퍼런스로 씁니다. 여러 개를 골라 한 번에 받을 수 있습니다. 받은 자료의 저작권은 쓰는 사람이 확인해야 합니다.

## 기능별 사용법 (예시와 함께)

처음 쓰는 기능은 여기 순서대로 따라 하면 됩니다. 메뉴 이름은 화면에 보이는 그대로 적었습니다.

### 앱 전체에서 같은 것

- **경로 칸**: 폴더·파일 경로를 넣는 칸은 **칸을 누르면** 고르기 창이 열립니다(따로 [고르기…] 단추가 없습니다). 직접 치려면 Tab으로 칸에 들어갑니다.
- **파일 고르기 창**: 왼쪽에 모든 드라이브와 ★ 즐겨찾기 폴더가 보입니다. 칸이 비어 있으면 늘 **앱이 있는 폴더**에서 열립니다(C: 사용자 폴더로 가지 않습니다).
  - 오른쪽 **미리보기**에서 고르기 전에 내용을 확인합니다.
    - 그림은 작은 그림과 크기가 보입니다.
    - 영상은 앞부분 한 장면이 보입니다. 뒤에서 만드는 거라 1~2초 걸리고, 한 번 본 영상은 바로 나옵니다.
    - 소리는 **▶ 들어 보기** 단추가 생깁니다.
    - 자막·글 파일은 앞의 몇 줄이 보이고, 폴더는 안에 든 항목 수가 보입니다.
  - 아래 줄에서 할 수 있는 것:
    - **정렬**: 이름 · 바뀐 날짜 · 자주 쓰는 순으로 늘어놓습니다.
    - **☆ 즐겨찾기**: 지금 폴더를 왼쪽 목록에 고정합니다.
    - **최근 파일…**: 이 창으로 고른 파일 30개 가운데 지금 고르는 종류에 맞는 것만 보여 줍니다. 예를 들어 그림을 고를 때는 그림만 나옵니다.
- **입력 칸 목록 (▾)**: 오른쪽에 ▾가 있는 칸은 누르면 고를 수 있는 값과 **최근에 쓴 값**이 펼쳐집니다. 글자를 치는 동안에는 맞는 값이 아래에 뜹니다.
  - 예: 예약 공개 시각 칸 → `18:00` · `21:00` 같은 자주 쓰는 시각과 지난번에 쓴 시각이 나옵니다.
  - 예: 매크로의 프로그램 칸 → 지금 떠 있는 프로그램 이름(`StarRail.exe` 등)이 나옵니다.
  - 목록 맨 아래 **최근 목록 비우기**로 지웁니다. 암호 칸은 기억하지 않습니다.
- **창 크기**: 창은 처음 뜰 때 내용이 다 보이는 크기로 열리고(화면의 92%까지), 다음부터는 마지막에 쓴 크기로 열립니다. 창 제목 줄을 두 번 누르거나 최대화 단추로 크게 볼 수 있습니다.
- **Alt + 밑줄 글자**: 메뉴·칸 이름의 밑줄 글자와 Alt를 같이 누르면 그 칸으로 갑니다. 목록 칸이면 목록이 바로 펼쳐집니다.

### 출력 폴더 (설정 → 폴더)

내보낸 결과가 갈 곳을 종류별로 정합니다. 비워 두면 작업 폴더의 `Outputs`에 들어갑니다.

| 칸 | 들어가는 것 | 예 |
|---|---|---|
| 롱폼 | 내보낸 편집본 영상 | `D:\편집본` |
| 숏폼 | 쇼츠 영상 | `D:\쇼츠` |
| 자막 | 편마다 저장한 SRT | `D:\자막` |

썸네일 창의 **작업할 영상** 목록은 이 폴더들과 방송 정리의 보관 폴더에서 영상을 찾습니다.

### 디자인 (도구 → 디자인)

썸네일 · 일정표 · 자유 디자인이 한 창의 탭으로 모여 있습니다.

**썸네일 만들기 — 예: 지난 방송 다시보기 썸네일**
1. 위쪽 **템플릿 줄**에서 틀을 고릅니다. 최근에 쓴 틀이 앞에 옵니다. 그림·요소는 **고른 템플릿에만** 바뀝니다(다른 템플릿은 그대로).
2. 왼쪽 **작업할 영상**에서 영상을 고릅니다. 노션 방송일정의 부제와 그날 찍은 스크린샷이 미리 깔립니다.
3. 아래 **배경 후보**에서 그림을 고릅니다. 연결한 폴더에 있는 그림만 나옵니다(한 번 썼다고 계속 남지 않습니다). 지난 썸네일은 **히스토리** 탭에 있습니다.
   - 카페 탐방처럼 PV 장면을 쓸 때: 장면을 복사하고 캔버스에서 **Ctrl+V** — 새 요소로 들어옵니다.
4. 캔버스에서 요소(배경·틀·로고·도장·글·붙인 그림)를 손봅니다. 모두 같은 방식입니다.
   - 누르기: 고르기 (Ctrl·Shift로 여러 개, 빈 곳을 끌면 사각형으로) — 고른 요소는 테두리와 모서리 손잡이가 보입니다.
   - 끌기: 옮기기 — 캔버스 가장자리·가운데·다른 요소 가장자리에 **자석처럼 붙고** 빨간 기준선이 보입니다(Alt를 누르고 끌면 안 붙음).
   - 휠: **마우스를 올린 요소**의 크기 · Ctrl+휠: 돌리기 · 모서리 손잡이 끌기: 크기
   - **F** = 캔버스에 꽉 채우기 · **Shift+F** = 다 보이게 · 방향키 = 조금씩 옮기기
   - **Ctrl+Z / Ctrl+Y** 되돌리기·다시 하기 · Delete 빼기 · Ctrl+D 복제 · Ctrl+C 고른 요소를 그림으로 복사
5. 오른쪽 **요소** 판
   - 목록: 위가 앞입니다. 체크 = 보이기, 두 번 누르기 = 이름 바꾸기.
   - ＋ 파일 그림 · ★ 스티커(틀·로고·도장 폴더의 그림을 더 얹기) · ⧉ 붙여넣기 · ↑↓ 앞뒤 순서 · ✕ 빼기
   - 고른 요소의 불투명도·밝기·대비·채도·색조, 필터(흑백·세피아·흐리게·선명하게·반전), 좌우 뒤집기, 잠그기
   - **배경 지우기**(내 컴퓨터 AI로 투명 PNG) · **AI 요청 →**(고른 요소들을 한 그림으로 합쳐 AI에 보냄, 결과는 새 요소로 얹히고 원래 것은 숨김)
   - **템플릿 처음대로**: 요소 자리·크기·색을 템플릿 기본으로 (배경 그림과 글은 둡니다)
6. 오른쪽에서 글을 고칩니다.
   - 윗줄에는 버전·회차가 들어갑니다(예: `3.8 上`).
   - 제목에는 부제의 「」 안 글이 들어갑니다.
   - **글 모양…**에서 글꼴·색·테두리를 바꿉니다. 게임마다 정해 둔 글꼴이 먼저 적용됩니다.
7. **썸네일 저장**을 누르면 영상 옆에 `영상이름.thumb.png`로 저장됩니다.
   - 시안을 하나 더 만들려면 **새 썸네일로 저장**을 누릅니다. `.thumb-2.png`로 저장됩니다.
   - 이미 올린 다시보기 영상이면 유튜브 썸네일도 바로 바뀝니다.

- **틀·로고·도장 그림**: `Templates\thumbnails\게임 이름` 폴더에 투명 PNG를 넣고 **다시 읽기**를 누르면 목록에 생깁니다. 화면 크기 그대로 받은 그림(어도비 익스프레스 등)은 그린 자리 그대로 얹힙니다.
- **게임별 도장**: 컨텐츠 창의 도장 칸이 비어 있으면 '자동 — 틀 폴더에서 찾음'으로 보입니다. 썸네일은 틀 폴더의 도장을 씁니다. 다른 그림을 쓰려면 칸을 눌러 고릅니다.
- **AI로 다시 그리기**: 요소를 고르고(안 고르면 배경) 요청을 적은 뒤 **AI로 만들기**(비우면 애니풍으로 다시 그리기). 결과는 **원본 ↔ AI**로 비교합니다. ChatGPT 웹으로 하려면 배경을 클립보드에 넣고 ChatGPT를 엽니다. 거기서 받은 그림을 다운로드하면 저절로 들어옵니다.
- **지난 방송**: 트레이 아이콘 오른쪽 클릭 → **지난 방송 정리 다시 열기**에서 방송을 고르면 그 방송의 썸네일·부제를 다시 만들 수 있습니다.

**주간 일정표**: `Templates\schedule`에 배경 프레임과 스티커 3장을 넣어 두면 기본 틀이 만들어집니다.
- 스티커는 첫째가 휴방, 둘째가 저챗, 셋째가 마스코트입니다.
- 노션 방송일정을 읽어 칸을 채웁니다. 제목에 '저챗'이 있는 날은 저챗 스티커가 붙습니다.
- 칸의 스티커는 오른쪽 클릭 → **이 날만** 또는 **'이름'에 기억**으로 바꿉니다.

### 스크린샷 (도구 → 스크린샷)

매크로와 따로 있는 기능입니다. 단축키 하나로 앞에 떠 있는 창을 찍어 그 프로그램 폴더에 넣습니다.

1. **단축키** 칸에 키를 적고 **단축키 정하기**를 누릅니다(예: `ctrl+alt+s`, `printscreen`). 비워 두면 스트림덱 `shot`으로만 찍습니다.
2. **찍는 방식**을 고릅니다.
   - 창 안쪽만: 게임 화면만 찍습니다. 다른 창에 가려져 있어도 찍힙니다.
   - 창 전체: 테두리까지 찍습니다.
   - 모니터 전체: 그 창이 있는 모니터를 통째로 찍습니다.
3. 파일 형식(PNG/JPG)을 고릅니다.
4. **프로세스별 저장 폴더**: 프로그램마다 폴더를 따로 정합니다.
   - 추가: **＋ 실행 중인 프로그램에서…**(떠 있는 창을 그림으로 보고 고르기) 또는 **＋ 이름으로**(예: `StarRail.exe`)
   - 폴더 정하기: **폴더 고르기…**. 비우면 `기본 폴더\이름`에 저장합니다.
   - 등록하지 않은 프로그램은 `기본 폴더\프로세스 이름`으로 들어갑니다.
5. **시험 찍기**를 누르고 3초 안에 찍을 창을 앞으로 가져옵니다.

파일 이름은 `이름 2026-01-31 21-05-33.png`처럼 찍은 시각이 붙습니다.

### 매크로 (도구 → 프로그램별 매크로)

프로그램마다 동작 목록을 만들어 두고, **통합 키**(또는 스트림덱 `macro`)를 누르면 앞에 떠 있는 프로그램의 매크로가 돕니다.

1. 프로그램을 등록합니다. **실행 중인 프로그램에서…**로 고르거나, 프로그램 칸에 이름을 적습니다(여럿이면 쉼표로).
2. 동작을 넣습니다. 손으로 넣거나 녹화합니다.
   - **손으로**: 넣을 수 있는 동작은 다음과 같습니다.
     - 키(조합 `ctrl+s`, 연타 횟수·간격)
     - 키 누르고 있기
     - 마우스 누르기(왼쪽·오른쪽·가운데), 누르고 있기, 끌기
     - 옮기기, 휠, 글자 넣기
     - 창 앞으로(프로그램 찾아 활성화, 없으면 실행), 기다리기, 찍기(스크린샷)
     - 마우스 자리는 **창 그림에서 고르기…**로 그 창 그림 위를 눌러 정합니다. 창 크기가 바뀌어도 같은 자리를 누르도록 비율로 기억합니다.
   - **녹화**: **⏺ 녹화**를 누르고 게임에서 하던 대로 키보드·마우스를 씁니다. 멈추려면 `F10`을 누릅니다.
     - **간격도 기록**을 켜면 동작 사이 시간이 '기다리기'로 들어가고, 끄면 동작만 빠르게 들어갑니다.
     - 정해 둔 시간보다 오래 누른 키는 '누르고 있기'로, 같은 키를 빠르게 여러 번 누르면 '연타'로 적힙니다.
3. **되풀이**: 매크로를 몇 번 돌릴지 정합니다. 0은 멈출 때까지입니다. 도는 중에 멈추려면 매크로 창의 **멈추기**나 스트림덱 `macro.stop`(도는 매크로 멈추기)을 씁니다.
4. **시험 실행**을 누르고 3초 안에 그 프로그램을 앞으로 가져옵니다.

예: 원신에서 UI 숨기기 → 찍기 → UI 되돌리기는 `키 f6` → `기다리기 300ms` → `찍기` → `키 f6` 순서로 넣습니다.

### 스트림덱 버튼 (도구 → 스트림덱 버튼 만들기)

스트림덱 플러그인 없이 기본 동작 **System → Open**으로 CastEdit 기능을 부릅니다.

1. **빠르게**에서 자주 쓰는 버튼을 고르거나, **기능**을 직접 고릅니다.
2. 기능마다 필요한 칸을 채웁니다. 칸의 ▾를 누르면 고를 수 있는 값이 나옵니다.
   - `on` = `1` 켜기 · `0` 끄기 · 비우면 뒤집기
   - `db` = `+3`·`-3`(지금보다 크게·작게), `0`(그 값으로)
   - `cmd` = `playpause`·`next`·`prev` 등 (유튜브 뮤직)
3. 아래 **명령 줄**을 복사해 스트림덱 'System → Open'의 App/File 칸에 붙여 넣습니다.
4. **지금 눌러 보기**로 바로 시험합니다.

게임 PC 일(매크로·스크린샷)은 그 PC에서 합니다. 송출 PC 일(OBS 장면·소스·음소거·마커, 디코 마이크 섞기, 유튜브 뮤직)은 송출 PC 도우미가 합니다. **설정 → 일반 → 원격 조작**이 켜져 있어야 스트림덱이 부를 수 있습니다.

### 디코 마이크 섞기 (보이스미터 대신)

송출컴 도우미 → **디코 마이크 섞기**. 마이크와 게임컴 반주를 앱이 섞어 디스코드로 보냅니다.

1. **① VB-CABLE 설치…**를 누릅니다. 공식 사이트에서 받아 관리자 권한으로 설치합니다. 확인 창 두 번이 뜨고, 끝나면 PC를 다시 시작합니다.
2. 디스코드 → 설정 → 음성 → 입력 장치를 **CABLE Output**으로 바꿉니다(한 번만).
3. 도우미에서 **디코 마이크**·**반주 → 디코**를 켜고 크기를 맞춥니다. **도우미를 켜면 같이 켜기**를 켜 두면 다음부터 저절로 켜집니다. OBS 마이크를 보이스미터에서 옮길 때는 **② OBS 마이크를…** 단추를 한 번 누릅니다.
4. 방송 중에는 스트림덱 `mix.mic`(마이크) · `mix.song`(반주) · `obs.mic`(OBS 마이크 음소거)로 켜고 끕니다.

**케이블이 빠졌다 꽂히면**: 목소리 효과와 디코 마이크 섞기는 3초마다 토핑 장치를 확인합니다. 빠지면 '장치 끊김'으로 기다리다가, 다시 꽂히면 같은 설정으로 저절로 다시 켜집니다. 다시 켤 필요가 없고, 몇 번 다시 켰는지는 도우미에 보입니다. 장치가 없을 때 [켜기]를 눌러도 '기다리는 중'으로 남았다가 꽂히는 대로 켜집니다.

### 낭독 — 등장 인물 그림 (비주얼 노벨 창에서 `C`)

인물마다 초상·읽는 사람·등장 화·설명이 카드로 보입니다.

- **거르기**: 위 줄에서 성별 · 읽는 사람 · 그림 출처 · 그림 상태 · 이름/설명 찾기로 좁혀 봅니다.
  - 그림 상태: 제 그림 / 대역 그림 / 실루엣 대역 / 그림 없음 / 제 그림이 없는 인물
  - 예: '그림 상태 → 실루엣 대역'을 고르면 아직 제 그림이 없어 실루엣으로 서는 인물만 보입니다. 그림을 새로 받아야 할 목록이 됩니다.
- **그림 출처**: 그림 아래 칸에서 정합니다. 대역이면 대역 그림의 출처가 보입니다.
  - 출처 종류: **공식 그림** · **원작 삽화** · **AI 제작** · **실루엣** · **출처 모름**
  - 인터넷 주소로 받은 그림은 처음부터 '공식 그림'입니다.
  - 그 아래 글(어디서 왔는지 — 작품·만든 사람)은 두 번 눌러 고칩니다.
- **실루엣 대역**: 장면 파일에 남녀 실루엣을 정해 두면, 그림도 대역도 없는 인물이 말할 때 성별에 맞는 실루엣이 섭니다.
  - 정해 두는 자리: `"fallback": {"m": "실루엣(남성)", "f": "실루엣(여성)"}`
  - 성별 모름인 인물에는 실루엣이 서지 않습니다.
  - 나중에 `인물\이름.png`를 넣으면 그 그림이 먼저 나옵니다.
- **모습 바꾸기 (가면·실루엣 등)**: 한 인물의 다른 모습은 `이름(설명).png`로 넣습니다.
  - 예: `도슨트(가면).png`, `라피스(실루엣).png`
  - 비주얼 노벨 화면에서 바꿀 문단에 가서 오른쪽 클릭 → **여기부터 모습 바꾸기** → 인물 → 그림을 고릅니다.
  - 그 문단부터 그 인물이 말할 때도, 장면 칸에 서 있을 때도 그 그림으로 나옵니다.
  - 끝나는 문단에서 **원래 그림**을 고르면 돌아옵니다.
  - 화가 바뀌면 원래 그림부터 시작합니다. 낭독회 웹에도 그대로 올라갑니다.
- **그림 붙이기**: 카드의 **그림 붙이기…**로 붙이거나, 그림 폴더 `인물\<이름>.png`로 넣고 **그림 폴더 다시 살피기**를 누릅니다.

### 방송 정리 · 채널 연결

- **설정 → 방송 정리 → 채널**에서 본 채널과 다시보기 채널을 따로 연결합니다.
  - 연결할 때 뜨는 구글 창에서 **올릴 채널(브랜드 계정)을 직접 고르세요.** 계정 선택 창이 매번 뜨게 해 두었습니다.
  - 이미 다른 칸에 연결한 채널을 고르면 연결하지 않고 알려 줍니다.
- 치지직 연결 중 **"스코프가 필요합니다"**(403)가 뜨면 치지직 개발자 센터의 앱 설정에서 **방송 설정 조회·변경** 권한을 켜고 다시 연결하세요.

## 자주 쓰는 단축키

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| `Space` | 재생 / 정지 | `J` `K` `L` | 뒤로 / 정지 / 앞으로 (누를수록 빠르게) |
| `←` `→` | 한 프레임 | `↑` `↓` | 이전 / 다음 편집점 |
| `I` `O` | 시작 / 끝 표시 | `Ctrl+Shift+K` | 모든 트랙 자르기 |
| `Shift+Del` | 잔물결 삭제 | `Ctrl+Z` | 되돌리기 |
| `Shift+2` `Shift+4` | 원본 / 편집본 보기 | `F1`~`F4` | 작업 공간 |
| `Ctrl+T` | 받아쓰기 | `Ctrl+M` | 내보내기 |
| `M` | 마커 | `Shift+F` | 멈춘 화면 효과 켜고 끄기 |
| `Shift+Space` | 미리보기 렌더 | `Ctrl+O` `Ctrl+W` | 열기 / 닫기 |

모든 단축키는 **파일 → 설정 → 단축키**에서 바꿀 수 있습니다(겹치면 빨간색으로 표시). 한글 입력 상태에서도 단축키가 동작합니다.

## 파일은 어디에 저장되나

- **녹화 원본은 바꾸지 않습니다.**
- **작업 폴더**(설정 → 폴더 → 작업)를 정하면 앱이 만드는 모든 것이 그 아래에 모입니다. 기본은 앱 폴더의 `Data`(예: `E:\CastEdit\Data`)이고, 칸에 지금 쓰는 곳이 보입니다. 다른 곳으로 바꾸면 옮길지 먼저 묻고, 설정·편집 내용·템플릿·기록·백업을 복사합니다(예전 폴더는 지우지 않습니다).
  - `Settings`: 설정·단축키·화면 배치
  - `Projects`: 편집 내용
  - `Outputs`: 내보낸 영상
  - `Assets`: 효과음·음악·그림
  - `Cache`: 파형·받아쓰기 결과·프록시 등
  - `Temp`: 임시 파일
  - `Backups`: 자동 백업
- 캐시와 임시 파일은 앱이 알아서 정리합니다. **설정 → 저장 공간**에서 용량을 보고 한도를 정하거나 바로 비울 수 있습니다.
- 엔진(ffmpeg·Whisper 등)은 크고 PC마다 따로 필요해서 윈도우 사용자 폴더(`%LOCALAPPDATA%\cast-ops\cast-edit\tools`)에 둡니다.
- 비밀 값(로그인 연결·웹후크 등)은 파일이 아니라 윈도우 자격 증명에 저장합니다.
- 설정을 다른 PC로 옮길 때는 설정 → 일반 → **지금 설정 내보내기…**로 프리셋 파일을 만들고, 그 PC에서 **가져오기…**합니다(비밀 값은 빠집니다).

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 실행하자마자 `python312.dll`을 못 찾는다는 창 | `CastEdit.exe`만 따로 꺼낸 경우입니다. 설치 파일(`CastEdit-Setup-버전.exe`)로 설치하거나, zip을 모두 풀어서 실행하세요 |
| "ffprobe 없음"으로 영상이 안 열림 | 최신 버전은 ffmpeg를 자동으로 받습니다. 받는 중이면 끝날 때까지 기다리고, 실패했으면 위쪽 띠의 **ffmpeg 다시 받기**나 설정 → 엔진 관리를 이용하세요 |
| 재생 중에 효과·자막이 안 보임 | 재생 엔진(libmpv)이 없어 기본 재생기로 돌고 있는 상태입니다. 위쪽 띠의 **재생 엔진 받기**를 누르면 앱을 다시 켜지 않고 바로 바뀝니다 |
| 파형이 안 보임 | 영상을 다시 열면 새로 만듭니다. 계속 안 보이면 설정 → 엔진 관리에서 ffmpeg 상태를 확인하세요 |
| 받아쓰기가 너무 느림 | 설정 → 음성 인식에서 장치가 그래픽카드(cuda)로 되어 있는지 확인하세요. 처음 한 번은 모델(약 3GB)을 받느라 오래 걸립니다 |
| "Windows의 PC 보호" 창 | **추가 정보 → 실행**을 누르세요 |

문제가 계속되면 상태 줄의 메시지와 함께 만든 사람에게 알려 주세요.
